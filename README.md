# BPB Warp Scanner - MTS Edition

Fork for MTS LTE with Amnezia noise.

## Quick Start

Run on Android via Termux with install.sh

## Amnezia Config

- Jc = 4 (Junk Count)
- Jmin = 40
- Jmax = 70

## MTS Profiles

1. Standard: Jc=4, Jmin=40, Jmax=70
2. Aggressive: Jc=6, Jmin=30, Jmax=80
3. Conservative: Jc=3, Jmin=50, Jmax=90

## Profile Selection

Use install-advanced.sh for profile selection
